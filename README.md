JoelAustin.Net is the personal website and professional portfolio of Joel Austin, a software engineer specializing in frontend development with experience across web, mobile, and backend technologies. The site showcases an engaging, animated interface featuring an "About Me" section highlighting hobbies like cooking, guitar, and Japanese language studies alongside professional experience at IPC Systems and the University of Pittsburgh, a skills showcase spanning React, Angular, Node.js, Python, AWS, and more, and a portfolio of projects including award-winning mobile apps (BABL language matcher and DormStack dorm social platform) from the Pitt Mobile App Challenge as well as full-stack work like the Pitt Menu Parser capstone with REST API, database design, and smart assistant integrations. A development blog documents the iterative building process behind these projects, and the site itself serves as a living demonstration of frontend craftsmanship with smooth transitions, responsive design, and polished UX. The live site at joelaustin.net is currently being refreshed, while this repository archives the original React-based v1 implementation.
